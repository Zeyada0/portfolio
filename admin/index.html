  1. افتح GitHub → Fine-grained token
  2. Token name: portfolio · Expiration: 1 year
  3. Repository access: Only select repositories ثم اختار portfolio
  4. Permissions → Repository permissions → Contents: Read and write
  5. Generate token وانسخه، وحطه تحت
